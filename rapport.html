Securite des donnees

Les mots de passe sont haches avec bcrypt (cout de travail eleve). Les sessions utilisateur sont gerees par Flask-Login avec des tokens securises. Les requetes SQL passent toutes par l'ORM SQLAlchemy, protegeant contre les injections SQL.

Algorithme de matching

L'algorithme calcule un score de compatibilite sur 100 entre un mentor et un mentore, selon trois criteres ponderes :

Score_total = 0.50 × Score_competences + 0.30 × Score_horaires + 0.20 × Score_filiere

Score competences (50%)

Proportion des lacunes du mentore couvertes par les forces du mentor :
|Forces_mentor ∩ Lacunes_mentore| / |Lacunes_mentore| × 100

Score horaires (30%)

Chevauchement en minutes entre les disponibilites des deux utilisateurs, normalise sur le total disponible du mentor.

Score filiere (20%)

Meme filiere → 100pts. Filieres proches (cluster STEM) → 50pts. Differentes → 20pts. Bonus +20 si mentor meme niveau ou superieur.

Seuls les matchs avec un score ≥ 10 sont conserves. Les resultats sont tries par score decroissant et les 10 meilleurs sont presentes a l'utilisateur.

Instructions de deploiement

Prerequis

Python 3.10+, PostgreSQL 14+, Git

Installation pas a pas

Cloner le depot 
git clone https://github.com/[GROUPE]/PIL1_2526_XX.git
cd PIL1_2526_XX
Creer l'environnement virtuel et installer les dependances 
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
Creer la base de donnees PostgreSQL 
psql -U postgres
CREATE DATABASE mentorlink_db;
CREATE USER mentorlink WITH PASSWORD 'mentorlink';
GRANT ALL PRIVILEGES ON DATABASE mentorlink_db TO mentorlink;
\q
Configurer les variables d'environnement 
# Creer un fichier .env a la racine
DATABASE_URL=postgresql://mentorlink:mentorlink@localhost/mentorlink_db
SECRET_KEY=votre-cle-secrete-aleatoire
Initialiser la base de donnees 
# Option A : utiliser le fichier SQL directement
psql -U mentorlink -d mentorlink_db -f schema.sql

# Option B : via Flask CLI
flask --app run init-db
Lancer l'application 
python run.py
# L'application sera disponible sur http://localhost:5000

Manuel d'utilisation

Creer un compte

  1. Acceder a /auth/register
  2. Renseigner : prenom, nom, email, telephone, mot de passe
  3. Choisir sa filiere et son niveau
  4. Cocher ses points forts (matieres maitrisees) et points faibles (ou on a besoin d'aide)
  5. Valider l'inscription → redirection vers la connexion

Trouver un mentor

  1. Se connecter et acceder au tableau de bord
  2. Cliquer sur "Trouver un mentor" dans la navigation
  3. L'algorithme calcule automatiquement les matchs selon tes lacunes, disponibilites et filiere
  4. Consulter le score de compatibilite detaille pour chaque mentor propose
  5. Cliquer sur " Contacter" pour ouvrir une conversation

Publier une annonce

  1. Cliquer sur "Publier une annonce"
  2. Choisir le type : Offre de mentorat ou Demande de mentorat
  3. Renseigner le titre, la description, le format (en ligne / presentiel)
  4. Selectionner les matieres concernees
  5. Ajouter les disponibilites horaires
  6. Publier → l'annonce apparait dans la liste publique

Envoyer un message

  1. Acceder a la Messagerie via la navigation
  2. Cliquer sur une conversation existante ou contacter un utilisateur depuis son profil
  3. Taper le message et appuyer sur Entree ou cliquer
  4. Les messages arrivent en temps reel grace a WebSocket

Modifier son profil

  1. Cliquer sur " Parametres" en haut a droite
  2. Modifier les informations, la photo, les competences ou les disponibilites
  3. Enregistrer → les matchs seront recalcules lors de la prochaine recherche
